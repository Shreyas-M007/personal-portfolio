# Personal Portfolio

This is the repository for my personal portfolio website, live at: https://shreyas-m.is-a.dev

## Overview
A clean, interactive dashboard built using vanilla web technologies. It displays my academic metrics, current course timeline at BMSCE, and my development skills using a 3D flipping card layout.

## Tech Stack
- HTML5
- CSS3 (Custom properties, 3D transforms, responsive flex/grid layouts)
- JavaScript (Vanilla DOM manipulation, canvas particle network animation)

## Features
- **3D Dashboard Cards**: Click or tap to flip cards for details on academic timelines, courses, and credentials.
- **Academic Scorecard**: Comparative progress bars for semester SGPA and cumulative GPA.
- **Node Network Background**: Interactive particles canvas that reacts to mouse movement.
- **Quick Contact Tiles**: Interactive tiles that copy email addresses directly to the clipboard.

## Running Locally
To test the site locally, clone the repository and run a local server:
```bash
python -m http.server 7000
```
Then open `http://localhost:7000` in your web browser.
